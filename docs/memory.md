# 长期记忆

让 AI 好友跨会话记住用户，而不是每次从零开始。

## 问题

`ai-agent.ts` 只带最近 20 条消息：

```
昨天  你：最近天天加班到十点，好累
      她：辛苦了，早点休息吧
今天  你：今天也累
      她：辛苦了，早点休息吧   ← 完全不记得
```

## 三层记忆

| 层 | 内容 | 实现 |
| --- | --- | --- |
| 工作记忆 | 当前会话最近 20 条 | `ai-agent` 的 `HISTORY_LIMIT` |
| **长期记忆** | 跨会话的事实 | `MemoryItem` 表 + 召回注入 |
| 原始日志 | 全部消息 | `Message` 表（不进 prompt） |

关键：长期记忆**不是**把聊天记录塞进上下文，而是压缩成几条事实。

## 数据模型

```prisma
model MemoryItem {
  id          String    @id @default(cuid())
  scope       String    @default("user") // user | global
  userId      String?                     // scope=user 时必填
  kind        String    @default("fact") // fact | doc（doc 预留给知识库）
  content     String
  keywords    String                      // 空格分隔，用于召回
  confidence  Float     @default(0.8)
  sourceMsgId Int?                        // 可追溯到原始消息
  expiresAt   DateTime?                   // 「在加班」这类会过期
  createdAt   DateTime  @default(now())
  lastUsedAt  DateTime?
  usedCount   Int       @default(0)

  user User? @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@index([userId, kind])
  @@index([scope])
}
```

`scope` + `userId` 保证**按人隔离**，`kind=doc` 为后续知识库预留同一张表。

## 抽取

规则抽取（确定性、零延迟、离线可用），示例：

| 规则 | 匹配 | 产出 |
| --- | --- | --- |
| 加班 | `加班｜熬夜｜通宵` | 最近经常加班或熬夜，比较累（TTL 14 天） |
| 疲惫 | `好累｜压力大｜扛不住` | 最近压力偏大，容易觉得累（TTL 14 天） |
| 职业 | `我是程序员｜设计师…` | 职业是X（长期） |
| 名字 | `我叫X` | 名字叫X（长期） |
| 喜好 | `我喜欢X｜我讨厌X` | 喜欢/不喜欢X（长期） |
| 宠物 | `我养了X猫` | 养了X猫（长期） |

去重：同 `userId + content` 只更新置信度和过期时间，不新增行。

抽取是**异步**的，在回复落库之后执行，不阻塞主链路。

## 召回

```
用户消息
  ↓
1. 关键词命中（必须带 userId 过滤，防串号）
  ↓
2. 若命中数为 0，但用户说了「记得吗｜上次｜之前」
   → 退化为按时间取最近的记忆
  ↓
3. 打分 = 意图 + 命中数 + 新鲜度 + 置信度
  ↓
4. 取 top 3，注入
```

加「显式回忆意图」的原因：用户问「你还记得我最近在忙什么吗」时，
「忙」并不在事实关键词里（关键词是 加班/累/工作），纯关键词召回会返回空。

## 注入措辞实验（关键）

同一个问题「今天也累」+ 同一条记忆，不同注入方式结果差异很大：

| 方案 | 注入内容 | 回复 |
| --- | --- | --- |
| V0 | 无记忆 | 辛苦了呢…要我帮你做些什么来放松一下嘛？ |
| V1 | `…。对方最近总加班，很累。` | 是吗？那我给你按摩一下吧 |
| V2 | `…` + 换行追加 | 啊，这样啊，辛苦了，记得多喝热水（变长、说教） |
| V3 | `…（对方最近总加班）` | 累坏了吧？来和我分享一下你今天累成什么样子的？ |
| V4 | `[对方的情况]` + 指令块 | **是啊，最近经常加班或熬夜，好累** ← 逐字复述 |

直接问「你还记得我最近在忙什么吗」：

| 措辞 | 回复 |
| --- | --- |
| 无记忆 | 不记得喵！你最近在忙什么呀？ |
| 「你知道对方…」 | 我记不得，不过没关系的… |
| **「你记得对方说过…」** | **当然记得呀！你最近总加班到十点，很累的说** ✅ |

结论：**「你记得对方说过：…」** 是唯一稳定生效的措辞，
「你知道」会触发否认，指令块会触发逐字复述。

## 效果验证

清空会话历史（只剩记忆），发送「你还记得我最近在忙什么吗」：

```
灵儿：你还记得我最近在忙什么吗
沐雪：当然记得呀，最近经常加班或熬夜，比较累；最近压力偏大，容易觉得累
```

`/api/memory` 可见 `usedCount` 递增，说明召回链路生效。

## 局限

| 局限 | 说明 |
| --- | --- |
| 规则抽取覆盖面有限 | 「我同事叫小王」这类抽不到 |
| 召回是关键词级 | 「上次那个事」这类模糊指代接不住（需要向量层） |
| 回复可能复述 | 4B 模型会把事实原样念出来，偶尔偏长 |
| 无冲突消解 | 先后说了「在加班」「辞职了」，两条都会留着 |
